Endpoints

All endpoints accept POST with a JSON body {"question": "..."} and an X-API-Key header.

POST/v1/substitute

What can replace an ingredient? Returns historically attested swaps with source citations.

POST/v1/modernise

Rewrite an old recipe with modern supermarket ingredients, metric measurements, and plain-English instructions.

POST/v1/convert

Convert historical measurements — gills, drachms, wine-glasses — to modern ml/g/cups equivalents.

POST/v1/explain

Decode old cooking terms and techniques. "Scald the milk", "lard the fowl" — explained in plain modern terms.

GET/v1/crossref/{ingredient}

Full cross-reference entry: all known substitutes, consensus scores, citation counts, earliest year seen.

GET/v1/stats

Corpus statistics: total books, substitution pairs, coverage by decade.

Quick Start

curl Python 
# Ingredient substitution
curl -X POST https://api.oldrecipe.io/v1/substitute \
  -H "X-API-Key: your-api-key" \
  -H "Content-Type: application/json" \
  -d '{"question": "What can I substitute for lard in a pie crust?"}'

# Response
{
  "answer": "For pie crust, butter is the most commonly cited substitute for lard across historical sources. Mrs Beeton (1861) recommends equal weight of butter; The White House Cook Book (1887) suggests a half-and-half blend of butter and dripping for a flakier result. Vegetable shortening (post-1911) is a later option.",
  "sources": [
    {
      "ingredient": "lard",
      "substitute": "butter",
      "book": "Mrs Beeton's Household Management",
      "year": 1861,
      "diet_tags": ["vegetarian"]
    }
  ],
  "latency_ms": 143
}
